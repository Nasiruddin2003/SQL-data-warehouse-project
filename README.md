# Brazilian E-Commerce Data Warehouse & Analytics

## 📌 Overview

A SQL Server data warehouse and analytics project built using the Brazilian E-Commerce dataset from Olist.

The project follows a **Bronze → Silver → Gold** architecture and focuses on data loading, cleaning, transformation, and analytical reporting.

## 🛠️ Tools

* Microsoft SQL Server
* SQL Server Management Studio (SSMS)
* SQL

## 🏗️ Architecture

* **Bronze:** Raw data ingestion
* **Silver:** Data cleaning and transformation
* **Gold:** Business-ready analytical data

## 🎯 Key Areas

* Customer and order analysis
* Product and sales analysis
* Seller performance
* Revenue and order trends
* Exploratory Data Analysis using SQL

## 📚 Learning Reference

This project is an implementation inspired by the Data Warehouse and Analytics project methodology taught by **Data with Baraa**, adapted to the Olist Brazilian E-Commerce dataset.
