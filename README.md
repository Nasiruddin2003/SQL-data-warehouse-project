# Brazilian E-Commerce Data Warehouse & Analytics

## Project Overview

A SQL Server data warehouse and analytics project using the Olist Brazilian E-Commerce dataset. The project follows a Bronze → Silver → Gold architecture for data processing and analysis.

## Project Requirements

### Data Warehouse

* Load and integrate the Olist CSV datasets.
* Clean and transform the data.
* Build Bronze, Silver, and Gold layers.
* Develop a structured data model for analytical queries.
* Focus on the available dataset without implementing data historization.

### Analytics

Analyze:

* Customer Behavior
* Product Performance
* Sales Trends
* Seller Performance

## Learning Reference

This project is an implementation inspired by the Data Warehouse and Analytics project methodology taught by **Data with Baraa**, adapted to the Olist Brazilian E-Commerce dataset.
